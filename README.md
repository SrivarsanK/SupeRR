# SupeRR: reliable under pressure

My entry for **SupeRR Selector Season 2, Round 1** (Rajasthan Royals x Unstop): a data-driven ranking of the
batters and bowlers who perform best in high-pressure situations, for RR's IPL 2027 auction.

## How it works

1. **Pressure index.** Every ball in the IPL and T20I data (2022 to 2026, 200,961 balls) gets a score from the
   match state before it is bowled: the required rate in a chase, wickets lost against par for that over, and
   balls left. The top 25% of balls are high pressure.
2. **Ball value.** Each ball is compared with an average player in the same format, innings, over and pressure
   band: runs above par, minus 6 runs for a dismissal. Bowlers get the mirror image.
3. **Pressure Elo.** Every high-pressure ball is a batter-against-bowler duel, rated ball by ball in date order
   (K = 2), so runs off strong bowlers count for more. The same Elo on normal balls gives each player's baseline.
4. **Eligibility.** At least 120 high-pressure balls in 12 or more matches, a match since January 2025, and only
   players RR can sign (no Pakistan internationals, no IPL retirees).
5. **Checks.** The lists are re-run with a different pressure cut-off and a different wicket value, and players
   are rated on odd and even matches separately to see whether the rating repeats.

The report covers each step, every pick's profile and the limitations in full.

## Reproduce

The contest data pack is not in this repository: the contest rules do not allow it to be shared. Put it at
`data/6af458274c1e8_data_pack/Data Pack/`, then:

```bash
pip install pandas numpy matplotlib
python analysis/pressure.py --check   # ratings, checks -> analysis/out/
python analysis/report.py             # report PDF -> analysis/report/, data -> dashboard/players.js
```

The PDF is printed with Microsoft Edge (path set in `report.py`).

To view or deploy the dashboard, copy the taste-skill kit's `assets` folder into `dashboard/assets` (it is
git-ignored), then serve `dashboard/` as a static site, for example `vercel deploy --prod` from that folder.
